## 📌 오늘 학습한 주제

**웹 서비스 이해 5강 — API의 이해**

## 💡 오늘 배운 것

### 1. 개발 도구(IDE / 코드 편집기) 선택
* **IDE vs 코드 편집기**: 자바 전용인 이클립스(Eclipse)보다는, 다양한 언어와 확장 팩(플러그인) 활용이 뛰어난 **VS Code(Visual Studio Code)** 를 프론트엔드(HTML, CSS, JavaScript) 및 리액트 개발 환경으로 선택함.
* **VS Code 설치**: 공식 홈페이지에서 운영체제(Windows 등)에 맞는 인스톨러를 다운로드하고, 라이선스 동의 및 기본 설정을 거쳐 간단하게 설치 가능.

### 2. 프로젝트 디렉토리 구조 잡기
* **작업 폴더 생성**: C 드라이브 루트 등에 `vscode_project` 같은 루트 디렉토리를 만들고, 하위에 `front/web` 구조로 프론트엔드 전용 작업 폴더를 구성함.
* **VS Code 프로젝트 오픈**: `File > Open Folder`를 통해 해당 `web` 폴더를 프로젝트 루트로 불러와 작업 환경을 세팅함.

### 3. 정적 리소스와 웹 서버 (Live Server)
* **정적 리소스**: HTML, CSS, JavaScript, 이미지 등 별도의 서버 로직 없이 브라우저가 그대로 처리하는 리소스.
* **Live Server 확장 팩**: VS Code 확장(Extensions) 탭에서 `Live Server`를 설치하여, 로컬 환경에서 웹페이지를 실시간으로 테스트하고 실행할 수 있도록 함.

### 4. 프로젝트 파일 및 폴더 정리
* **HTML 파일 생성**: `login.html` 등을 만들고 `html:5` 단축키를 활용해 기본 뼈대(구조, 헤더, 바디)를 빠르게 구성.
* **역할별 디렉토리 분리**: 소스코드가 뒤섞이지 않도록 `css/`와 `script/` 폴더를 용도별로 나누어 관리.
* **Material Icon Theme**: 파일과 폴더의 확장자를 직관적으로 파악할 수 있도록 아이콘 테마 확장 팩을 설치하여 가독성을 높임.
