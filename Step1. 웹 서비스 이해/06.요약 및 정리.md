## 💡 오늘 배운 것 흐름 요약

### 1. HTML 구조와 코딩 기본기
* **구조와 가독성**: 태그는 `<tag attr="value">text</tag>` 형태로 구성되며, 태그 안에 다른 태그를 중첩하여 뼈대를 만듦. 코드가 지저분하면 가독성이 떨어지므로 들여쓰기 와 대소문자 구분을 철저히 지키는 것이 중요함.
* **주석 활용**: HTML에서는 `<!-- 주석 내용 -->` 형태로 코드를 설명하거나 비활성화할 수 있음.

### 2. Live Server를 통한 로컬 배포
* 원격 서버에 요청을 보내 브라우저로 화면을 확인하는 개념을 이해하고, VS Code의 **Live Server** 확장 팩을 활용해 로컬 환경(`localhost:5500`)에서 실시간으로 웹페이지 구동 결과를 확인함.

### 3. CSS를 통한 화면 스타일링
* **선택자(Selector)**: 스타일을 적용할 대상을 지정하는 방식으로, 태그명(예: `body`)이나 클래스명(도트(`.`)로 시작하는 `.login-container`)을 사용함.
* **파일 분리 및 연결**: 스타일 코드를 HTML에 직접 쓰지 않고 별도의 `login.css` 파일로 분리하여 재사용성을 높이고, `<head>` 태그 안의 `<link>` 태그로 연결함.

### 4. JavaScript를 통한 동적 기능 구현
* **이벤트 처리와 DOM 조작**: 사용자가 로그인 버튼을 누르는 등의 행동을 **이벤트(Event)** 로 인식하고, JS를 통해 폼(Form) 제출을 제어(`e.preventDefault()`)함.
* **로그인 검증 로직**: `document.getElementById()`를 통해 HTML 요소에 접근하여 입력값을 가져오고, 조건문(`if/else`)을 통해 아이디와 비밀번호를 검증한 뒤 성공 시 `window.location.href`로 페이지를 이동시킴.
