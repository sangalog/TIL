## 💡 오늘 배운 것

### 1. 클래스는 변수와 메서드로 구성

클래스(Class)는 객체를 만들기 위한 설계도이다.

클래스 안에는 크게 두 가지 요소가 들어간다.

- **변수(Field)** : 데이터를 저장
- **메서드(Method)** : 데이터를 처리하는 기능

```java
public class Person {

    String name; // 변수

    public void introduce() {
        System.out.println("안녕하세요");
    }
}
```

| 구성 요소 | 역할 |
| ---------- | ---------- |
| 변수 | 객체의 상태(데이터)를 저장 |
| 메서드 | 객체의 동작(기능)을 정의 |

> 클래스는 데이터를 담는 공간과 데이터를 처리하는 기능을 함께 정의하는 설계도이다.


### 2. 메서드(Method)란?

메서드는 데이터를 처리하는 기능이며, 필요하다면 매개변수를 통해 값을 전달받고 처리 결과를 반환할 수 있다.

- 재료를 담아두는 그릇 → 변수
- 재료를 조리하는 과정 → 메서드

즉, 메서드는 데이터를 활용하여 원하는 결과를 만들어 내는 역할을 한다.

```java
접근제어자 반환타입 메서드명(매개변수) {

}
```

예시

```java
public int add(int a, int b) {
    return a + b;
}
```

### 3. 지역 변수(Local Variable)

메서드 내부에서 선언한 변수를 지역 변수라고 한다.

```java
public void printMessage() {
    String message = "Hello";
}
```

지역 변수의 특징

- 선언된 블록 내부에서만 사용 가능
- 블록을 벗어나면 접근 불가
- 메서드 실행이 끝나면 사라짐

```java
public void test() {
    int age = 20;
}

System.out.println(age); // 오류

=> age는 test() 메서드 내부에서 선언된 지역 변수이므로 메서드 밖에서는 사용할 수 없다.
```
### 4. Scope(스코프)란?

스코프(Scope)는 변수를 사용할 수 있는 범위를 의미한다.

| 종류 | 사용 가능 범위 |
|--------|--------|
| 지역 변수 | 선언된 블록 내부 |
| 필드(멤버 변수) | 클래스 전체 |

> 변수는 선언 위치에 따라 사용할 수 있는 범위가 달라진다.

### 5. 메서드의 4가지 유형

#### ① 매개변수 X, 반환값 X

```java
public void hello() {
    System.out.println("Hello");
}
```

#### ② 매개변수 O, 반환값 X

```java
public void printName(String name) {
    System.out.println(name);
}
```

#### ③ 매개변수 X, 반환값 O

```java
public String getName() {
    return "홍길동";
}
```

#### ④ 매개변수 O, 반환값 O

```java
public int add(int a, int b) {
    return a + b;
}
```

### 6. 반환 타입(Return Type)

반환 타입은 메서드가 실행 후 돌려주는 데이터의 타입이다.

반환값이 없으면 `void`를 사용한다.

```java
public void print() {

}
```

반환값이 있으면 해당 데이터 타입을 지정한다.

```java
public int getAge() {
    return 20;
}
```

```java
public String getName() {
    return "홍길동";
}
```
