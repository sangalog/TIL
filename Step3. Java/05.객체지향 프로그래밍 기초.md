## 💡 오늘 배운 것

### ① 클래스(Class) vs 인스턴스(Instance)

* **클래스 (Class)**: 객체를 생성하기 위한 틀(Template / 설계도)이다. 메모리에 로드된 상태가 아닌 명세(Specification)에 불과하다.
* **인스턴스 (Instance)**: 클래스라는 설계도를 바탕으로 메모리(Heap 영역)상에 실제 구체화된 실체(Object)이다.

> **개념의 구별**: 클래스 자체를 인스턴스라고 불러서는 안 된다. 템플릿(클래스) 없이 인스턴스를 만들 수 없지만, 둘은 엄연히 명세와 실체의 관계이다.

### ② 왜 인스턴스를 생성해야 하는가? (멤버의 소유권)

클래스에 정의된 변수(인스턴스 변수)와 메서드(인스턴스 메서드)는 클래스 자체의 소유가 아닌, **생성될 인스턴스의 소유**가 된다.

* 클래스 단독으로는 내부의 변수나 메서드를 사용할 수 없으며, 접근 권한도 없다.
* **`new` 키워드를 통해 객체(인스턴스)를 생성해야만** 메모리에 공간이 할당되고, 해당 멤버들이 해당 인스턴스의 소유로 활성화되어 외부에서 접근할 수 있게 된다.

### ③ 참조 타입(Reference Type)과 객체 생성 과정

```java
Teacher tea = new Teacher();
```

위 코드는 다음과 같이 두 부분으로 나누어 이해할 수 있다.

1. **`Teacher tea` (변수 선언)**
   * `Teacher`라는 클래스는 기본 데이터 타입(Primitive Type)이 아닌 사용자 정의 참조 타입(Reference Type)이다.
   * `tea` 변수는 실제 객체 값이 아닌, 생성될 객체의 메모리 주소값(Reference)을 담는 그릇 역할을 한다.

2. **`new Teacher()` (인스턴스 생성 및 메모리 할당)**
   * `new` 키워드는 Heap 메모리에 `Teacher` 객체를 위한 공간을 새로 할당한다.
   * 생성된 객체의 **메모리 주소**가 대입 연산자(`=`)를 통해 참조 변수 `tea`에 저장된다.

### ④ 메모리 참조 연산자 (`.`)와 인스턴스 접근

참조 변수에 주소값이 저장되면, 점 연산자(`.`)를 사용하여 해당 인스턴스가 소유한 변수와 메서드에 접근할 수 있다.

* **변수 접근**: `tea.name = "jslim";`
* **매개변수/반환값이 없는 메서드 호출**: `tea.eating();`
* **매개변수와 반환값이 있는 메서드 호출**: `String result = tea.teaching("자바");`

### ⑤ [추가 개념] `String[] args` vs `String args[]` 차이점

자바 문법에서 배열 변수를 선언할 때 대괄호(`[]`)의 위치에 따른 차이는 다음과 같다.

| 구문 | 대괄호(`[]`) 위치 | 특징 및 권장 여부 |
| :--- | :--- | :--- |
| **`String[] args`** | 타입(`String`) 뒤 | **자바 표준 권장 방식.** <br>`String[]` 전체를 하나의 타입(문자열 배열 타입)으로 명확히 인식할 수 있어 가독성이 뛰어나다. |
| **`String args[]`** | 변수명(`args`) 뒤 | C/C++ 언어와의 문법적 호환성을 위해 남겨둔 자바의 이전 작성 스타일이다. |

* **기능적 차이**: 두 작성 방식 모두 **동일하게 동작**하며 컴파일 결과나 기능상의 차이는 전혀 없다.
* **권장사항**: 자바 생태계와 코드 컨벤션에서는 **`String[] args`** 스타일을 표준 형태로 강력히 권장한다.

```java
// 동일하게 작동하는 예시
public static void main(String[] args)  // 자바 표준 권장 방식
public static void main(String args[])  // C/C++ 스타일 (기능은 동일)
```

### ⑥ 실습 코드 분석

#### 1) 템플릿 클래스 (`Teacher.java`)

독립적으로 실행되지 않고 인스턴스 생성을 위한 틀 역할을 하는 클래스이다. (`main` 메서드 없음)

```java
public class Teacher {
    // 인스턴스 변수 (속성)
    public String name;
    public int age;
    public String address;
    public boolean isMarraige;

    // 인스턴스 메서드 1: 반환값 X, 매개변수 X
    public void eating() {
        System.out.println("강의하기 위해서 밥을 먹는다.");
    }

    // 인스턴스 메서드 2: 반환값 O (String), 매개변수 O (String)
    public String teaching(String subject) {
        return "강사님이 가르치는 과목은 " + subject + " 입니다.";
    }
}
```

#### 2) 실행 클래스 (`TeacherApp.java`)

프로그램의 엔트리 포인트(`main` 메서드)를 포함하며, `Teacher` 인스턴스를 생성하고 활용한다.

```java
public class TeacherApp {

    public static void main(String[] args) {
        // 1. 참조 변수 선언 및 Teacher 인스턴스 생성 (주소값 저장)
        Teacher tea = new Teacher();

        // 2. 인스턴스 변수에 접근하여 값 할당 및 출력
        tea.name = "jslim";
        System.out.println(tea.name); // 출력: jslim

        // 3. 인스턴스 메서드 호출 (반환값 없는 메서드)
        tea.eating(); // 출력: 강의하기 위해서 밥을 먹는다.

        // 4. 인스턴스 메서드 호출 (인자 전달 및 반환값 수신)
        String result = tea.teaching("자바");
        System.out.println(result); // 출력: 강사님이 가르치는 과목은 자바 입니다.
    }
}
```
