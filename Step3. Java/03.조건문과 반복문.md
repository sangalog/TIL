## 📌 오늘 학습한 주제

**Java 3강 — 변수와 데이터 타입**

## 💡 오늘 배운 것

### 1. 변수

**변수는 데이터를 저장하는 공간이고, 타입은 저장할 데이터의 종류를 정하는 기준**이다.

```java
int age = 24;
```

| 구성 | 의미 |
| --- | --- |
| `int` | 정수를 저장하는 타입 |
| `age` | 나이를 나타내는 변수 이름 |
| `= 24` | 변수에 24를 저장 |
| `;` | 변수 선언문의 끝 |

> **타입은 데이터의 종류, 변수명은 데이터의 의미**를 나타낸다.

### 2. 기본 타입과 참조 타입

| 구분 | 저장하는 것 | 예시 |
| --- | --- | --- |
| **기본 타입** | 정수·실수·문자·논리 등의 값 | `int`, `double`, `char`, `boolean` |
| **참조 타입** | 객체를 가리키는 참조값 | `String`, 배열, 직접 만든 클래스 |

참조값은 **객체를 찾아갈 수 있는 정보**라고 이해하면 된다. 흔히 주소에 비유하지만, 자바에서 실제 메모리 주소를 직접 다루는 것은 아니다.

**기본 타입은 총 8개이며, String은 기본 타입이 아닌 참조 타입이다.**

| 분류 | 타입 | 크기 | 선언 예시 |
| --- | --- | --- | --- |
| 정수 | `byte` | 1바이트 | `byte level = 10;` |
| 정수 | `short` | 2바이트 | `short year = 2026;` |
| 정수 | `int` | 4바이트 | `int age = 24;` |
| 정수 | `long` | 8바이트 | `long population = 8000000000L;` |
| 실수 | `float` | 4바이트 | `float temperature = 36.5F;` |
| 실수 | `double` | 8바이트 | `double height = 175.5;` |
| 문자 | `char` | 2바이트 | `char grade = 'A';` |
| 논리 | `boolean` | 언어 명세에서 저장 크기를 고정하지 않음 | `boolean isMarried = false;` |

- 정수 타입은 **표현할 수 있는 범위**가 다르며, 일반적인 정수에는 `int`를 사용한다.
- 실수 타입은 **표현 범위와 정밀도**가 다르며, 일반적인 실수에는 `double`을 사용한다.

**문자와 문자열은 따옴표로 구분한다.**

```java
char grade = 'A';       // 작은따옴표: 문자
String name = "홍길동"; // 큰따옴표: 문자열
String text = "A";      // 글자가 하나여도 문자열
```

> `char`는 정확히는 UTF-16 코드 단위 하나를 저장한다. `'A'`, `'가'`는 담을 수 있지만 일부 이모지는 char 하나로 표현할 수 없다.

### 3. 선언·초기화·할당의 차이

변수는 기본적으로 **타입과 이름**을 지정해 선언한다.

```java
int age;    // 선언
age = 24;   // 처음 값을 할당
age = 25;   // 값을 다시 할당
```

선언과 초기화를 한 번에 할 수도 있다.

```java
int age = 24;
```

| 용어 | 의미 |
| --- | --- |
| **선언** | 변수의 타입과 이름을 정하는 것 |
| **초기화** | 변수에 처음 사용할 값을 정하는 것 |
| **할당(대입)** | 변수에 값을 저장하는 것 |

> **`=`는 ‘같다’가 아니라 오른쪽 값을 왼쪽 변수에 저장하는 연산자**다. 값이 같은지 비교하는 연산자는 `==`이다.

변수명은 `age`, `userName`처럼 **소문자로 시작하는 카멜 케이스**를 사용한다. 이는 문법상 강제가 아닌 작성 관례다. 논리형 변수에는 `isMarried`처럼 `is`를 붙여 상태를 나타내기도 한다.

### 4. 선언 위치에 따라 달라지는 변수

| 구분 | 선언 위치 | 특징 |
| --- | --- | --- |
| **필드(멤버 변수)** | 클래스 안, 메서드 밖 | 객체나 클래스의 정보를 저장 |
| **지역 변수** | 메서드·블록 안 | 선언된 범위 안에서 사용 |

```java
public class Member {
    private String name = "홍길동"; // 필드

    public void introduce() {
        String message = "안녕하세요"; // 지역 변수
        System.out.println(message + ", " + name);
    }
}
```

- `name`은 필드이므로 같은 클래스의 다른 메서드에서도 사용할 수 있다.
- `message`는 지역 변수이므로 `introduce()` 밖에서는 사용할 수 없다.
- 필드는 초기값을 생략하면 타입에 따라 `0`, `false`, `null` 등의 기본값을 받는다.
- **지역 변수는 자동으로 기본값이 들어가지 않으므로, 읽기 전에 값을 할당해야 한다.**

클래스 안에 있는 변수를 모두가 쓸 수 있는 ‘전역 변수’로 이해하기보다는 **필드**로 구분하는 것이 정확하다.

**필드에는 접근 범위를 정할 수 있다.**

```text
[접근 지정자] 변수타입 변수명 = 값;
```

| 접근 지정자 | 의미 |
| --- | --- |
| `public` | 클래스 외부에서도 접근할 수 있도록 공개 |
| `private` | 기본적으로 해당 클래스 내부에서 사용하도록 제한 |

> 접근 지정자는 필드에 사용할 수 있지만, **지역 변수에는 public·private을 붙이지 않는다.**

### 5. 여러 타입으로 회원 정보 표현하기

[파일명 **VariableApp.java**]

```java
public class VariableApp {
    public String name = "홍길동";
    public int age = 24;
    public double height = 175.5;
    public boolean isMarried = false;
    public char gender = 'M';
}
```

모두 **클래스 안, 메서드 밖에 선언한 필드**다. `static`이 없으므로 객체마다 따로 가지는 **인스턴스 필드**에 해당한다.

이 클래스에는 `main` 메서드가 없어 단독 프로그램의 실행 시작점으로 사용할 수는 없지만, **컴파일은 가능하며 다른 코드에서 객체를 만드는 설계도로 사용할 수 있다.**

> **main은 실행 시작점이며, 모든 클래스가 main을 가져야 하는 것은 아니다.**
