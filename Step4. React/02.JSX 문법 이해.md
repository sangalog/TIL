## 📌 오늘 학습한 주제

**React 2강 — JSX 문법 이해**

## 💡 오늘 배운 것

### 1. Node.js 설치하기

React 개발 환경을 만들기 위해 먼저 **Node.js**를 설치한다.

1. Node.js 사이트에서 Windows용 **MSI 설치 파일**을 다운로드한다.
2. 설치 프로그램을 실행하고 기본 설정으로 설치를 진행한다.
3. Node.js와 함께 설치되는 **npm**의 버전도 확인한다.

```bash
node --version
npm --version
```

버전을 확인하는 이유는 **설치 상태와 버전 차이로 생길 수 있는 문제를 확인하기 위해서**다.

### 2. Git Bash 준비하기

명령어를 입력할 환경으로 **Git Bash**를 사용한다.

- Git이 없다면 Windows용 설치 파일을 받아 설치한다.
- 프로젝트를 관리할 `front` 폴더에서 마우스 오른쪽 버튼을 누른다.
- 필요하면 **추가 옵션 표시**를 선택한 뒤 **Git Bash**를 연다.

### 3. React 프로젝트 생성하기

**npm은 Node.js의 패키지 관리자**다. 프로젝트 생성 시에는 `npx`로 `create-react-app`을 실행해 필요한 파일과 패키지를 준비한다.

```bash
npx create-react-app react_pjt
```

| 구성 | 의미 |
| --- | --- |
| `npx create-react-app` | CRA 방식으로 React 프로젝트 생성 |

### 4. 프로젝트 구조 살펴보기

| 폴더·파일 | 역할 |
| --- | --- |
| `node_modules` | 프로젝트에 필요한 패키지가 설치된 폴더 |
| `public/index.html` | React 화면을 표시할 HTML 문서 |
| `src/index.js` | HTML의 표시 영역과 App 컴포넌트를 연결하는 코드 |
| `src/App.js` | 화면을 구성하는 App 컴포넌트 |

이 프로젝트는 **하나의 HTML 페이지를 바탕으로 컴포넌트를 표시하는 SPA 구조**다.

### 5. 컴포넌트가 화면에 표시되는 과정

**① `index.html` — 화면이 들어갈 자리**

```html
<div id="root"></div>
```

처음에는 비어 있는 영역이다. `root`라는 ID를 통해 이 영역을 찾아 React 화면을 표시한다.

**② `App.js` — 화면을 구성하는 컴포넌트**

`App`은 함수 형태로 만들어진 컴포넌트다. 화면에 표시할 구조를 반환하고, `export`로 다른 파일에서 사용할 수 있도록 내보낸다.

**③ `index.js` — HTML과 컴포넌트 연결**

`import`로 App 컴포넌트를 가져오고, `index.html`의 `root` 영역에 렌더링하도록 연결한다.

> **App에서 화면 구성 → index.js에서 연결 → index.html의 root 영역에 표시**

컴포넌트 함수 자체가 화면에 보이는 것은 아니다. **컴포넌트가 반환한 결과를 바탕으로 화면이 만들어진다.** 화면을 컴포넌트로 나누면 재사용하기도 쉬워진다.

### 6. 개발 서버 실행하기

VS Code에서 **터미널 → 새 터미널**을 열고 Git Bash를 선택한다. 프로젝트 폴더에서 다음 명령어를 실행한다.

```bash
npm start
```

개발 서버가 실행되면 브라우저에서 **3000번 포트로 열린 React 화면**을 확인한다.

설치 직후 `npm` 명령어를 찾지 못한다면 **VS Code를 완전히 종료한 뒤 다시 실행**하고 `npm start`를 입력한다.
